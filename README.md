# 🌊 汉字流体 — Chinese Character Fluid

**8000 个汉字粒子**在旋流噪声场中流动，鼠标可扰动。诗意水墨风格。

## 🎮 在线体验

**[👉 点此打开](https://is-cau.github.io/FluidChar/)**

## 🖱️ 操作

| 操作 | 效果 |
|------|------|
| **移动鼠标** | 产生漩涡扰动力场 |
| **滚轮** | 调节扰动力度大小 |
| **空格** | 暂停/继续 |
| **↑ ↓** | 加速/减速流速 |
| **← →** | 减小/增大扰动力度 |
| **R** | 恢复默认参数 |

## ✨ 技术实现

- **旋流噪声场 (Curl Noise)**：基于 FBM 多层值噪声，生成天然无散向量场
- **流体粒子系统**：8000 个汉字粒子，每个独立速度、颜色、大小
- **HSL 染色**：白色字模通过 HSL 色相偏移实时染色，蓝青水墨色调
- **预渲染精灵**：所有汉字预渲染为 Canvas 精灵，运行时 drawImage 高效绘制
- **鼠标漩涡**：切向力 + 径向力混合，模拟真实流体扰动
